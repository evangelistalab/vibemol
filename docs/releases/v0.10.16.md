# VibeMol 0.10.16

VibeMol can now show Molden orbitals, set the view, draw vectors, and return
PNG snapshots from a notebook. The [cyclopropene notebook](../../python/examples/excited_state_vectors.ipynb)
compares ground- and excited-state forces at the same scale, shows the
dipole reversal, and draws the transition dipole with a two-headed arrow.

- Molden orbitals with spherical or Cartesian g shells now render.
- The orbital table groups fractional occupations into Core, Active, and Virtual.
- Per-atom vector components and free arrows follow rigid rotations.
  Whole-structure translations move point-anchored arrows and preserve per-atom
  vector components.
- A vector command that changes the structure adds one **Vectors** step to Edit
  history. Undo and Redo restore the complete vector state. Unchanged commands
  leave history intact.
- The release records 19 named members across the orbital, vector, and vector
  model namespaces, including `VibeMolVectorsModel.restore`.

A 0.10.16 session opened in 0.10.15 or earlier keeps per-atom vectors and drops
free arrows.

See the [command reference](../api/commands.md), [vector guide](../xyz-vectors.md)
and [notebook widget guide](../../python/README.md).
