# VibeMol 0.10.14

This release adds two-way notebook integration. The in-app interface and What's new text are unchanged.

- **Command registry v0.** `VibeMolCommands` lists supported commands, describes their parameters, and calls the existing application APIs. [Command reference](../api/commands.md)
- **Opt-in embed bridge.** Use `?embed=commands#vmtoken=…` to send commands from the parent page and read Edit selection and Calculations state. The bridge is inactive on ordinary launches. Its token only separates messages between embeds. Use a trusted parent page. [Embed protocol](../api/embed.md)
- **Jupyter viewer.** The `vibemol-widget` 0.1.0 package provides `vibemol.Viewer`. A notebook can load files, submit commands, and read selection state in later cells. The separate `python-widget` CI job tests the package in Chromium and headless JupyterLab. [Installation and demo](../../python/README.md)
