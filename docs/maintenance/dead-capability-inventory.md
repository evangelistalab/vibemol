## Limits

- Direct executable references are not transitive reachability: code that calls a capability may itself be unreachable.
- A UI handler can be wired to an element that never renders; this audit does not prove UI reachability. Dead DOM/els (Part C) is deferred.
- Export inventory covers direct members of every VibeMol namespace published in assets/app/js, including factory-return public APIs; nested object schemas and controller instance methods are not separate namespace members.
- Lexical aliases, destructuring and qualified static brackets are resolved. Computed dynamic property names, arbitrary reflection, runtime mutation and external consumers cannot be proved statically.
- Executable JS, HTML scripts and Python-embedded JS are scanned. Historical evidence/baselines, comments and prose are not callers. Unparseable Python string fragments retain explicit qualified member references and are listed separately.
- live includes product reads of exported data. Function imports/availability guards alone do not prove a product caller. deps-passed requires a recorded invocation in the specific receiving factory.
- Console/API intent is a reviewed disposition, not proof of a caller. Nothing in this audit authorizes removal.
