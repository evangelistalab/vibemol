# Appearance / Studio paired-control invariant

The 0.11 decision gate measured **zero same-scope divergences** on main
`dde75acdbd873de679138fdc508f2386159409c7`. The old “14 pairs, five diverged”
claim is not the current interface. Under the human's pre-decided branch, the
commands/declarative-controls program stops here: its present case is maintenance
cost, not an active duplication defect. Phase 0 and the command bus are unstarted.
There is no production change in this increment.

The older interface (`?workspaceLab=0`) has nine true pairs. Workbench already
consolidates them in Properties / Look; it has no duplicate same-scope pairs.
Atom and bond multiplier rows are physically moved into the editor, including
their existing range/text inputs. They are two shared controls, not four owners.

grouped Appearance Undo transactions. The preset selectors share `choose`.
Hidden adapters such as `elementColors` are inventoried but not mistaken for
additional live controls.

## Runtime measurement and enforcement

Run `python3 tests/e2e/paired_controls.py --output out/test-artifacts/paired-controls`.
It also runs inside `look_references.py`, retaining the ordinary 37-suite count
and intentionally empty accepted set. `--discover` records measurement only;
ordinary execution requires the committed exact census in
[paired-controls.json](../../tests/baselines/paired-controls.json).

The served-response probe observes the actual Appearance DOM, editor factory
registrations and getters, and the actual preset selectors. Canonical settings
are perturbed independently before any UI write, so a wrong writer cannot make
its pair disappear. Both existing handlers are then exercised from the same
canonical seed. The check compares typed complete exported settings, peer
readbacks, mutation/Undo traces, and requested versus actually applied values.
A normally returning setter is insufficient (#25).

There are 12 same-scope write cases over nine pairs (all `change` paths plus
the three live `input` paths), seven explicit-scope cases over four legacy
pairs, and five cases over three Workbench scope pairs. All 48 handler
invocations retain their raw requests, traces and readbacks. Every independent
comparand is emitted before an assertion can abort.

The census includes 57 original DOM fields in each layout, 83/79 editor factory
bindings in legacy/Workbench, and the complete post-consolidation field DOM.
These are field counts, including range/text endpoints and local editor/library
inputs, not counts of independent settings. Exact identities, getter reads,
ownership and availability guard against missing pairs and controls added
outside the factories. Known different scopes are explicitly enumerated; a new
one cannot excuse a failing invariant. Baseline updates need a reviewed reason,
not an observed count substituted for the expected one.

Eight negative controls reject type drift, different writers with equal final
values, two identical silent no-ops, disappearing/replaced pairs, raw controls
outside the binding factory, reclassified scope pairs and forged pass flags.
The independent contract recomputes checks from the raw readbacks.

Discovery calls the existing synchronous UI sync functions to read bindings;
actual UI writes still await fonts and two presented-frame callbacks. Each
layout gets a fresh serial browser context. The caller is retired first and
zero background/residual contexts are asserted. Product files are never edited
by the probe; original/served/harness hashes are retained under ignored
`out/test-artifacts/paired-controls/`.

This is a value/writer invariant at 1512×1000 with a loaded scalar fixture,
Classic style, custom surface colors and fog enabled. It does not replace native
pointer eligibility, placement, rendering, every recipe/viewport, or incomplete
focused-text drafts; those remain covered by their existing suites. No defect
is claimed and no tagged-base defect reproduction is implied. No extraction,
controller interface or production mutable binding is introduced. The complete
37/0/37, unchanged 102 captures twice/exact repeat, 48 slots/eight contexts/all
minima, units/WebKit/construction gate remains required.

For any later authorized 0.11 work, the invariant differs from 0.10.0's promise:
each intended visible change must be enumerated and checked individually, with
all other goldens unchanged. This decision-gate increment has none.
