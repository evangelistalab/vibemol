Connect Claude to VibeMol

You'll return to claude.ai afterwards.

Claude will be able to use the VibeMol tabs you open in this browser:

  • view and edit molecules, and change display settings
  • take screenshots of VibeMol and read its source code
  • run JavaScript only if you turn on "Allow scripts", approving each script

No account is created. This browser gets a random, anonymous ID that links its VibeMol tabs to this Claude connection. You can remove it anytime with "Forget this browser" in VibeMol's Claude menu.
