Help & Shortcuts

Tips

  • Orbit: mouse drag • Zoom: wheel • Pan: right-drag
  • Use View/Coords to adjust camera, target, and scene shift.
  • Atoms/Bonds can be toggled independently, and Multi bonds enables inferred double/triple-bond rendering. Keyboard shortcuts 1/2/3/4 switch Default/Toon/Kit/Glossy, and the Molecule style list also includes Ink, Depth fog, Neon wireframe, Watercolor, Lego/Voxel, Toon+hatching, X-ray layering, and Blackbody emission.
  • Multi-frame XYZ trajectories expose playback controls in the dedicated Trajectory window (play, frame slider, FPS, loop).
  • Optional vibrational mode sidecar files (.vib.json, ORCA .hess, and Psi4 output logs) expose mode playback controls in the dedicated Vibration window; click a frequency row to select and animate that mode, and view the IR spectrum with the active mode highlighted.
  • In edit mode, Add atom uses automatic angle snapping (180°, 120°, 109.5°, 90°, 60°) with in-scene guide overlays.
  • Use Element colors… to edit per-element colors and atom labels to show element symbols over atoms.
  • Use Save Preset / Load Preset to reuse visualization settings across sessions and CLI runs.
  • The Cartesian coordinates are displayed as red (X), green (Y), and blue (Z) arrows.

Shortcuts

  • S — Save PNG
  • B — Batch export all files
  • I — Toggle iso‑surfaces on/off
  • A — Toggle axis gizmo on/off
  • R — Shift active molecule center of mass to origin
  • 1/2/3/4 — Molecule style: Default / Toon / Kit / Glossy
  • Cmd/Ctrl+Z / Cmd/Ctrl+Shift+Z — Undo / Redo edit action
  • Edit mode: hold Shift while placing to bypass auto angle snapping
  • ←/→ or ↑/↓ — Previous / Next file (view preserved)
