# Change Log

All notable changes to the "vibemol" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [0.9.0] - 2026-09-21

- Bundle VibeMol v0.9.0 with the Workbench and Properties interface.
- Opening a molecular file loads supported sibling files as one batch; folders can also be opened from the Explorer or Command Palette.
- Preserve unsaved text content, pair vibration sidecars, and report individual file read failures.
- Wait for the app's file loader before sending initial files, fixing viewers that opened empty.
